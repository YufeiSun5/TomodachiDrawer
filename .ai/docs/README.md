# .ai/docs

Stable project documents live here: architecture notes, compliance notes, deployment notes, stage summaries, and closed records.

## Naming

Use lowercase kebab-case names, for example `api-contract.md` or `deployment-topology.md`.

## Create New Files When

- A decision is stable enough to outlive the active task.
- A closed stage needs a durable summary.
- A contract needs a source of truth.

## Do Not Create Files When

- The item is still open or blocked; use root `AI_BOARD.md`.
- The content duplicates `AGENTS.md`.
- The information contains secrets or local-only credentials.
