# .ai/agents

Custom AI agent definitions live here.

## Naming

Use `<name>.agent.md`.

## Create New Agents When

- A recurring role has clear responsibility, boundaries, and tool limits.
- The role maps to `frontend-ai`, `backend-ai`, `test-ai`, or `review-ai`.

## Do Not Create Agents When

- A prompt is enough.
- The role would need broad permissions without a clear boundary.
