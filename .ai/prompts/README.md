# .ai/prompts

Task entry prompts live here.

## Naming

Use `<task-name>.prompt.md`.

## Create New Prompts When

- A workflow is common enough to need a consistent start.
- The prompt can link to existing instructions or agents.

## Do Not Create Prompts When

- The task is one-off.
- The prompt would duplicate `AGENTS.md` or an instruction file.
