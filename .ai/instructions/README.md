# .ai/instructions

Domain-specific AI instructions live here.

## Naming

Use lowercase kebab-case names, for example `backend.md`, `frontend.md`, or `gpl-compliance.md`.

## Create New Files When

- A domain has stable, executable rules.
- The rules apply to a clear set of files.
- The file can include useful `description` and `applyTo` frontmatter.

## Do Not Create Files When

- The rule is temporary or task-specific; use `AI_BOARD.md`.
- The content is a stable design note; use `.ai/docs/`.
- The content duplicates `AGENTS.md`.
