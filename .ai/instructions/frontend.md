# Frontend Instructions

- Read `AI_BOARD.md` before changing page scope, user-visible flow, or API expectations.
- Formal UI text must go through i18n resources once the frontend exists.
- The first screen should be the usable upload/generation workflow, not a marketing landing page.
- Public gallery must only show approved drawings.
- Admin review pages must expose approve/reject/hide/delete states clearly.
- Do not use Nintendo official logos, direct UI assets, or copied game art in production UI.
- Keep API paths and DTO field names aligned with backend contracts.
