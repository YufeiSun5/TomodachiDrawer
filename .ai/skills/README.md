# .ai/skills

Reusable project-specific skills live here after a workflow has repeated enough to justify a stable procedure.

## Naming

Use one folder per skill: `.ai/skills/<skill-name>/SKILL.md`.

## Create New Skills When

- The operation has repeated at least three times.
- Inputs and outputs are clear.
- Steps are stable and project-specific.

## Do Not Create Skills When

- The task is generic reading, bug fixing, or one-off research.
- The workflow has not been validated in this project.
